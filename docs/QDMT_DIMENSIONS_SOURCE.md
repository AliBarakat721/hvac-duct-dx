# QDMT physical-dimension source

The QDMT `Equipment_Models` worksheet stores manufacturer net dimensions in
millimetres in `Width x Height x Depth` order. The verified source is:

- Manufacturer: Carrier / Miraco
- Catalogue: *Ceiling Concealed Ducted Split Systems*
- Revision: Rev. (0), 2012
- Source pages: 4, 10, and 11
- Dimension type: net dimensions (not installation clearances)
- Verification status: catalogue verified

The `53QDMT48-518` and `53QDMT60-518` outdoor model suffixes are preserved
exactly as supplied by the catalogue; their indoor models retain the `-718`
suffix.
